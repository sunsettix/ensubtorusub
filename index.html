ASS / SRT · актёры · цвет · конвертация

Subtitle Toolkit

Набор инструментов для работы с субтитрами .ass: перенос имён актёров между дорожками по таймингу, быстрая конвертация ASS → SRT, просмотр списка актёров с числом реплик, переименование и объединение актёров, покраска реплик по актёру (аналог «Set primary fill color» в Aegisub) и мастерская для чтения/редактирования реплик. Всё работает локально в браузере — файлы никуда не отправляются.

1Быстрая конвертация ASS → SRT

Загрузите один .ass файл и сразу получите .srt — теги оформления ({\..}), переносы \N и позиционирование убираются, остаётся только текст и тайминг.

3Мастерская субтитров

Загрузите .ass файл (или откройте один из файлов/результат выше), чтобы увидеть список актёров с числом реплик, переименовать или объединить актёров, покрасить реплики конкретного актёра (Set primary fill color) и просмотреть/отредактировать все реплики с таймингами в боковом списке.

Переименуйте актёра и нажмите Enter или уберите фокус с поля — изменения применятся ко всем его репликам. Чтобы объединить двух актёров, задайте им одинаковое имя — они сольются в одну строку.

Кнопка с образцом цвета применяет цвет как {\c&HBBGGRR&} в начало текста каждой реплики этого актёра — это соответствует «Set primary fill color» в Aegisub.
